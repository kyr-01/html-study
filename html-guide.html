1. HTML이란?

HTML은 웹페이지의 뼈대를 만드는 언어입니다.

집에 비유하면 이렇습니다.

  • HTML: 벽, 방, 문 같은 집의 구조 → "여기는 제목, 여기는 문단"
  • CSS: 벽지, 페인트 같은 꾸미기 → "제목은 빨간색, 크게"
  • JavaScript: 전기, 수도 같은 기능 → "버튼을 누르면 뭔가 일어남"

💡 HTML은 프로그래밍 언어라기보다 "이 내용은 무엇이다"라고 표시하는 언어입니다. 어렵게 생각하지 않아도 됩니다.

2. 태그: HTML의 기본 단위

HTML은 태그로 내용을 감싸서 만듭니다. 태그는 <와 > 꺾쇠괄호로 씁니다.

<p>안녕하세요</p>
  • <p>: 여는 태그 (여기서 시작)
  • 안녕하세요: 내용
  • </p>: 닫는 태그 (여기서 끝, 앞에 /가 붙음)

여는 태그부터 닫는 태그까지를 통째로 요소(element)라고 부릅니다.

💡 <br>(줄바꿈)이나 <img>(이미지)처럼 감쌀 내용이 없는 태그는 닫는 태그가 없습니다.

3. HTML 문서의 기본 구조

모든 HTML 파일은 이 틀로 시작합니다. 외울 필요 없이 복사해서 쓰면 됩니다.

<!DOCTYPE html>          ← "이 파일은 HTML이에요"라는 선언
<html lang="ko">         ← HTML 문서 시작 (한국어)
<head>                   ← 머리: 화면에 안 보이는 정보
    <meta charset="UTF-8">  ← 한글이 깨지지 않게 하는 설정
    <title>페이지 제목</title>  ← 브라우저 탭에 보이는 이름
</head>
<body>                   ← 몸통: 화면에 보이는 내용은 전부 여기에!
    <h1>안녕하세요</h1>
</body>
</html>

💡 핵심은 하나입니다. 화면에 보일 내용은 <body> 안에 쓴다.

태그 안에 태그를 넣을 수 있고, 이것을 중첩이라고 합니다. 안쪽 태그는 보기 좋게 들여쓰기(스페이스 4칸)를 합니다.

4. 제목과 문단

제목은 <h1>부터 <h6>까지 있고, 숫자가 작을수록 큰 제목입니다.

코드
<h1>가장 큰 제목</h1>
<h2>중간 제목</h2>
<h3>작은 제목</h3>
<p>이것은 문단입니다.</p>
<p>첫째 줄<br>둘째 줄 (br로 줄바꿈)</p>
<hr>
결과

가장 큰 제목

중간 제목

작은 제목

이것은 문단입니다.

첫째 줄
둘째 줄 (br로 줄바꿈)

💡 HTML 코드에서 엔터를 여러 번 쳐도 화면에서는 줄이 바뀌지 않습니다. 줄을 바꾸려면 <br>이나 새 <p>를 써야 합니다. <hr>은 가로선입니다.

6. 목록

<ul>은 점 목록, <ol>은 번호 목록입니다. 항목 하나하나는 <li>로 감쌉니다.

코드
<ul>
    <li>사과</li>
    <li>바나나</li>
</ul>

<ol>
    <li>일어나기</li>
    <li>세수하기</li>
</ol>

  • 바나나

  2. 세수하기

9. 표

<table> 안에 줄(<tr>)을 만들고, 줄 안에 칸(<th> 제목칸 / <td> 일반칸)을 넣습니다.

코드
<table border="1">
    <tr>
        <th>이름</th>
        <th>나이</th>
    </tr>
    <tr>
        <td>철수</td>
        <td>20</td>
    </tr>
</table>

10. div와 span: 내용을 묶는 상자

<div>와 <span>은 그 자체로는 아무 모양이 없고, 내용을 한 덩어리로 묶을 때 씁니다. 묶어 두면 나중에 CSS로 한꺼번에 꾸밀 수 있습니다.

  • <div>: 큰 상자. 한 줄을 통째로 차지합니다. (여러 문단, 목록 등을 묶을 때)
  • <span>: 작은 상자. 글자 사이에 끼워 넣습니다. (문장 속 단어 몇 개를 묶을 때)
코드
<div>
    <h3>오늘의 메뉴</h3>
    <p>점심은 <span style="color: red">김치찌개</span>입니다.</p>
</div>
결과

오늘의 메뉴

점심은 김치찌개입니다.

💡 이 페이지의 흰 상자들도 사실은 <section>(div와 비슷한 상자)에 CSS로 둥근 모서리와 그림자를 준 것입니다.

11. 입력 폼: 글자를 입력받기

회원가입, 검색창처럼 사용자가 무언가를 입력하는 칸은 <input>으로 만듭니다. type 속성에 따라 모양이 달라집니다.

코드
<label>이름: <input type="text" placeholder="홍길동"></label><br>
<label>비밀번호: <input type="password"></label><br>
<label><input type="checkbox"> 약관에 동의합니다</label><br>
<label>좋아하는 계절:
    <select>
        <option>봄</option>
        <option>여름</option>
    </select>
</label><br>
<button>가입하기</button>
결과 (직접 입력해 보세요)




type 값모양
text글자 입력칸
password입력하면 ●●● 로 가려지는 칸
checkbox체크 상자
date날짜 고르기
  • placeholder: 칸이 비어 있을 때 흐리게 보이는 안내 글자
  • <label>: 입력칸에 이름표를 붙입니다. 글자를 눌러도 칸이 선택됩니다.
  • <select>와 <option>: 펼쳐서 고르는 목록

💡 HTML만으로는 입력한 내용을 저장하거나 보낼 수 없습니다. 그 일은 JavaScript나 서버가 합니다. HTML은 칸을 만드는 것까지예요.

12. 주석: 나만 보는 메모

<!--와 --> 사이에 쓴 글은 화면에 나오지 않습니다. 코드에 설명을 남기거나, 잠깐 숨기고 싶은 부분을 감쌀 때 씁니다.

코드
<!-- 여기부터 자기소개 부분 -->
<p>안녕하세요!</p>
<!-- <p>이 문장은 숨겨집니다</p> -->
결과

안녕하세요!

💡 VS Code에서는 줄을 선택하고 Ctrl + / 를 누르면 주석을 바로 넣거나 뺄 수 있습니다.

13. CSS 맛보기: 꾸미기의 시작

HTML이 뼈대라면 CSS는 옷입니다. 글자 색, 크기, 배경 등을 정합니다. CSS를 쓰는 방법은 두 가지입니다.

방법 1. 태그에 바로 쓰기 (style 속성)

코드
<p style="color: blue; font-size: 24px;">파랗고 큰 글씨</p>
<p style="background: yellow;">노란 배경</p>
결과

파랗고 큰 글씨

노란 배경

규칙은 속성이름: 값; 입니다. 여러 개는 ;로 이어 씁니다.

방법 2. CSS 파일을 따로 만들어 불러오기

페이지가 많아지면 파일 하나에 모아 두는 것이 편합니다. 이 폴더의 세 페이지도 모두 style.css 하나를 같이 씁니다.

HTML 파일의 <head> 안
<link rel="stylesheet" href="style.css">
style.css 파일
h1 {
    color: purple;      /* 모든 h1 글자를 보라색으로 */
}
p {
    font-size: 18px;    /* 모든 문단 글자를 18px로 */
}
자주 쓰는 CSS뜻예시
color글자 색color: red;
background배경 색background: pink;
font-size글자 크기font-size: 20px;
text-align정렬text-align: center;
border테두리border: 1px solid black;
